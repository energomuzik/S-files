# S-FILES · v2 — отдел необъяснимых явлений

Онлайн-игра на **двоих агентов — САЛЛИ и МОЛДЕР** (паранормальный детектив по духу «Секретных материалов»).
Полностью статический сайт: HTML + CSS + JS без сборки — кладёте папку на GitHub Pages и играете.

Сделано переносом механик из **RETROPOLIA / RETRO CHALLENGE GENERATOR (RCG)** с вырезанием лишнего.

## Схема соединения пары (вместо «хост открывает карту» в RCG)

1. Оба игрока открывают сайт.
2. **САЛЛИ** нажимает «создать пару» → получает код из 4 букв.
3. **МОЛДЕР** вводит код → соединение P2P (PeerJS, как RCG; вкладки одного ПК — через BroadcastChannel мгновенно).
4. Третий в пару не попадает (отказ `pair-full`).
5. Оба оказываются в штабе ФБР. Дальше — см. «Штаб».

## Штаб ФБР (главное меню)

Тёмная комната, в окне мелькают фары полицейских машин.

- **Доска расследований** (центр) — дела с **S-номерами** (S-01, S-02…). Клик — дело, «Принять миссию».
- **Дверь со светом** (справа) — выход на активную миссию (миссию запускает хост-Салли; карта на доске больше ничего не стартует).
- **Стол агента** (слева):
  - **Лампа** — включается наведением.
  - **Телефон** ☎ (стационарный, 90-е) — «позвонить агенту» (SALLY/MOLDER — пароль агента) или пробить **номер машины** (FBI-113, MIA-0407…) / **кредитной карты** (4407…).
  - **Микроскоп** 🔬 — осмотр любого предмета инвентаря под увеличением (у каждого типа своя «находка»).
  - **Документы** 📊 — расходы агентов.
- **Ящики** (по центру) — весь инвентарь игрока + **архив кассет отделения**. Кассету Майами можно сразу посмотреть.
- **Тумба с ТВ + профессиональный VHS-магнитофон ФБР** (слева от двери):
  - Вставка кассеты из инвентаря/архива, **PLAY / PAUSE (без помех) / STOP / REW ⏪ / FF ⏩ / EJECT ⏏**, громкость.
  - **Крутилка JOG**: медленная перемотка туда-сюда кадр-за-кадром — чтобы расслышать едва слышные голоса и разглядеть трёхфутовую тень.
  - При перемотке — помехи и шум ленты, при паузе — чистый кадр.
- Кнопка **🛠 СОЗДАНИЕ КАРТ** в шапке — редактор миссий (временная, потом уберём).

## Система сохранений (новая схема)

- **На миссии игра НЕ сохраняется** (выход из миссии = возврат к последнему сейву штаба).
- **Выход из миссии в штаб (ESC / кнопка) — автосейв**:
  - Хост (Салли) собирает итоговый инвентарь: **все предметы обеих игроков** сливаются в один список (ничего не теряется).
  - Этот список рассылается обоим (`saveSync`) — **у обоих игроков инвентарь одинаковый**.
- На следующий день любой игрок, зайдя один, увидит все предметы.
- Предметы берутся на миссию из ящиков штаба (до 20 штук).

## Медаль со слоном (награда из RCG)

Игроки побеждают **Френди** в RETRO CHALLENGE GENERATOR, затем возвращаются в S-FILES по ссылке:

```
https://energomuzik.github.io/S-files/?medal=1
```

Медаль 🐘 кладётся в сейв (один раз), видна в ящиках штаба и под микроскопом. Также можно вручить награду из диалога NPC (give → medal).

## Дело S-02 · МАЙМИ МОЛЛ ИНЦИДЕНТ (встроенная миссия)

Загадочная **трёхфутовая тень** на ночной стоянке ТЦ, десятки полицейских машин.
- Фон миссии — фотография со стоянки (`assets/miami-mall.png`).
- VHS-кассета «Майами Молл Инцидент» (`assets/miami-mall.mp4`, 60 МБ) лежит **в ящиках штаба с самого начала** — вставьте её в видеомагнитофон и проматывайте крутилкой.
- На миссии: офицер Джонсон (диалог → рапорт), 2 ящика с лутом (фонарик, улика).

## Редактор карт (кнопка 🛠 в шапке)

- **Мои миссии**: создать/открыть/удалить (IndexedDB браузера).
- **Инструменты**: выбор/двигать, тайл (рисование протяжкой, R — поворот), ластик, ячейка (СТАРТ — спавн агентов, ровно одна; точки интереса), стена (протяжка), дверь с ключом 6 цветов, портал (зона → точка), NPC (спрайт + диалог), **ящик с лутом** (в игре лутается ПКМ; можно загрузить свою картинку ящика), **VHS-кассета** (MP4 файлом ≤25 МБ или URL с Яндекс.Диска), **предмет** (тип + название + описание/функция).
- **Редактор диалогов**: узлы (реплика), варианты ответов, «выдать предмет 🎁», флаги 🚩/👁 (показать вариант только при флаге), стартовый узел. Концовок нет — жанр другой.
- Фон миссии: JPEG до 2000px. Слои тайлов 2–6. Сетка 64px, привязка 16px.
- **Сохранить** — валидация (ровно 1 СТАРТ) → IndexedDB.

Чтобы встроенная миссия (S-02) открылась, в `js/app.js` найдите `builtinMap()` — там же видно, как устроен формат карты (его же генерирует редактор).

## Запуск и публикация

Локально (для теста): откройте `index.html` через любой статический сервер:
```
npx serve .
```

GitHub Pages: залейте содержимое папки в репозиторий `energomuzik.github.io/S-files` ( ветка `main`, или папка `docs/`), в Settings → Pages включите Pages.

Мультиплеер работает прямо с GitHub Pages (PeerJS-облако для знакомства, дальше прямой P2P). Для двух вкладок одного браузера — мгновенный локальный канал.

## Структура

```
index.html          — штаб, гейт выбора роли, сцены, миссия, редактор
css/menu.css        — доска/гейт/дело (наследие v1)
css/game.css        — штаб, VHS, инвентарь, миссия, редактор
js/net.js           — PeerJS-комнаты на двоих (порт RCG net.ts)
js/engine.js        — авторитетный движок миссии (порт engine.ts)
js/render.js        — canvas-рендер миссии, спрайты агентов
js/inventory.js     — сетка 10×6 (порт FrendyInv.tsx) + сейвы
js/vhs.js           — VHS-плеер: jog-крутилка, помехи, eject
js/hq.js            — данные дел (S-номера), сцены штаба
js/editor.js        — редактор карт (порт MapEditor.tsx)
js/app.js           — пара агентов, миссия, автосейв, сетевые сообщения
js/menu.js          — обвязка штаба: модалки, музыка, геймпад, медаль RCG
js/pad.js, js/ydisk.js — геймпад/джой-мышь и Яндекс.Диск (из v1)
assets/             — фото/видео Майами, спрайты агентов
```

|---|---|
| Ходьба | WASD / стрелки / геймпад |
| Говорить с NPC | E (рядом) |
| Подобрать предмет | F (рядом) |
| Лутать ящик | ПКМ по ящику |
| Инвентарь | Tab |
| Выход в штаб | Esc |
| Джой-мышь | F7 / L3 (правый стик, R2=ЛКМ, R1=ПКМ) |
